# **Arduino Projects & Experiments**

Coleção de projetos, exemplos, bibliotecas e recursos práticos de prototipagem com Arduino, controle de motores, sensores e automação.

---

## **Conteúdo do Repositório**

- **Controle de Motores:**
  - `Arduino_NEMA17_A4988`: Controle de motor de passo NEMA 17 utilizando o driver A4988.
  - `MotorDC_L293D`: Controle de motor de corrente contínua com ponte H L293D.
  - `MotorDePasso_comLN293D`: Acionamento de motor de passo com circuito integrado L293D.
  - `Servo Motores`: Controle angular e varredura de servomotores.
  - `2motores_1botao`: Acionamento sequencial/simultâneo de motores com controle por botão.
  - `AccelStepper`: Exemplos com controle de aceleração e velocidade.

- **Robótica & Sensores:**
  - `Carrinho com InfraRed`: Robô seguidor / controlado por infravermelho.
  - `sensorPalmas`: Acionamento por sensor de som / palmas.
  - `SensorUmidade`: Leitura e monitoramento de umidade.
  - `Eficient_receptor_light`: Sensor/receptor óptico de alta eficiência.
  - `varios_botoes_1_entrada`: Multiplexação de múltiplos botões usando uma única entrada analógica com divisor resistivo.

- **Bibliotecas e Recursos:**
  - `libraries`: Bibliotecas essenciais prontas para importação na Arduino IDE.
  - `biblioteca p proteus`: Modelos e esquemáticos para simulação no software Proteus.
  - `Projetos`: Sketches e códigos experimentais diversos.
  - `Livros Arduino`: Guias de referência e material de apoio.

---

## **Como Utilizar**

1. Abra a [Arduino IDE](https://www.arduino.cc/en/software).
2. Se necessário, instale as bibliotecas da pasta `libraries/` copiando para a pasta `Arduino/libraries` do seu sistema ou via *Sketch > Incluir Biblioteca > Adicionar biblioteca .ZIP*.
3. Conecte sua placa Arduino (Uno, Mega, Nano, etc.) via USB.
4. Abra o arquivo `.ino` do projeto desejado, selecione a porta COM correspondente e clique em **Carregar**.
